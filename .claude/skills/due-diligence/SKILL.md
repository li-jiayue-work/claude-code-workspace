# 企业深度尽职调查 Skill

## 概述

本 Skill 对目标企业进行系统性深度调查，输出覆盖十三大维度的完整情报报告。不仅涵盖合规风险，更深入企业战略、业务板块市场格局、董事会权力结构、关键人社会网络、重大事件战略解读等深度维度，帮助用户在求职、投资、合作前真正看透一家公司。

---

## 调查前准备

开始前确认（已知则跳过）：

1. **目标企业名称**（全称，避免同名混淆）
2. **调查目的**：求职 / 投资 / 商务合作 / 金融授信
3. **统一社会信用代码**（可选，有则更准确）
4. **关注重点**（可选，如"我主要想了解公司稳不稳定"）

---

## 十三大调查维度

---

### 维度一：主体基础信息

> 建立企业基本画像，确认调查对象无误。

| 字段 | 内容 |
|------|------|
| 企业全称 | |
| 统一社会信用代码 | |
| 企业类型 | 有限公司 / 股份公司 / 外资 / 国企 / 混合所有制 |
| 法定代表人 | |
| 成立日期 | （成立年限） |
| 注册资本 | （实缴比例） |
| 经营状态 | 存续 / 注销 / 吊销 |
| 注册地址 vs 实际办公地址 | （是否一致） |
| 上市状态 | 未上市 / 上市（交易所 / 股票代码 / 板块） |
| 经营范围摘要 | |
| 公司官网 / 主要对外渠道 | |

**风险信号**：注册资本实缴极低、注册地与经营地严重不符、经营状态异常。

---

### 维度二：工商合规风险

> 识别监管层面的合规问题。

- **经营异常记录**：是否被列入异常名录，原因及是否移出
- **行政处罚记录**：近3年处罚机关、事由、金额（重点关注重大处罚）
- **严重违法记录**：是否进入黑名单
- **近3年工商变更**：
  - 法定代表人变更（频繁为异常信号）
  - 注册资本变更（大幅缩水需关注）
  - 经营范围变更（战略转向信号）
  - 股东结构变更
  - 注册地址迁移

---

### 维度三：司法与执行风险

> 识别法律诉讼和执行风险，并对重大案件做深度解读。

- **失信被执行人 / 限高令**：是否存在，金额及履行情况
- **被执行记录**：案件数量、标的总额、未结案件
- **涉诉情况**：
  - 案件总数及近3年趋势
  - 角色（原告 / 被告 / 第三人）
  - 类型（劳动纠纷 / 合同 / 金融借贷 / 知识产权 / **刑事**）
  - 单案大额标的重点关注
  - **劳动纠纷数量尤其重要**（求职场景核心指标）
- **股权冻结 / 质押**：比例及原因
- **重大案件深度解读**（如有）：
  - 案件背后代表什么？（监管态度变化？行业整顿信号？竞争对手博弈？）
  - 最坏结果是什么？（罚款上限、业务限制、牌照吊销风险）
  - 已采取的应对措施及效果

---

### 维度四：股权结构与穿透

> 识别真实控制人，防范隐性关联风险。**不仅要向上穿透看谁控制公司，也要向下穿透看公司控制了谁。** 穿透层级 ≥ 3 级。

#### 4A. 向上穿透——谁控制了这家公司

- **直接股东层**：各方持股比例、股东类型
- **穿透路径**：逐层控股关系，直至自然人或国家持股
- **最终实际控制人**：姓名、国籍、自身风险状态
- **投票权结构**：单一股权/AB股/其他特殊安排
- **一致行动人/表决权委托/信托等控制权增强机制**
- **政府 / 国资背景判断**：
  - 股东层是否含国资委、地方国企、政府基金
  - 国资持股比例及层级位置
  - 是否有政府引导基金参与融资

**穿透格式示例**：
```
目标公司
└── A投资公司（持股60%）
    └── 张三（持股100%）← 最终实控人
└── 某市国资委（持股40%）← 国资背景
```

#### 4B. 向下穿透——公司控制了谁（对外投资图谱）

> ⭐ 这是最容易遗漏的维度。必须逐层梳理公司对外投资/参股/控股的全部实体。

- **控股子公司**（持股>50%）：逐一列出，说明主营业务及在集团中的角色
- **重要参股企业**（持股20%-50%或虽<20%但有董事会席位）：说明参股比例、投资目的
- **财务投资**（持股<20%，无重大影响）：可按行业分类汇总
- **VIE 实体**（如适用）：境内协议控制实体清单及各自业务
- **被投企业健康度**：是否存在风险传导（被投企业涉诉/破产/被查）
- **投资趋势**：近3年新增/退出投资的行业方向（扩张 vs 收缩）

**对外投资分类格式**：
```
控股子公司：
├── X公司（100%）— OTA核心运营主体，年营收XX亿
├── Y公司（80%） — 商旅管理
└── Z公司（51%） — 海外业务平台

重要参股：
├── A公司（30%）— 民宿平台，董事会席位
└── B公司（25%）— 目的地旅游

财务投资：
├── C基金（LP，出资X亿）
└── D公司（5%）
```

#### 4C. 业务板块与市场格局

> ⭐ 旗下各业务/平台不是铁板一块，必须逐一拆解。

- **业务板块拆分**：公司旗下有哪些业务线/子品牌/平台？各自主攻什么？
- **各板块市场份额**：
  - 在每个细分市场的排名和份额（能查到就查）
  - 主要竞争对手是谁？差距有多大？
- **各板块成长性**：哪些在增长？哪些在收缩？
- **品牌矩阵**：不同品牌定位（高端/中端/低端/海外），是否互相竞争

---

### 维度五：经营与资质风险

- **主营业务**：核心产品/服务，与注册范围是否匹配
- **行业资质 / 许可证**：必要资质是否齐全，有效期
- **知识产权**：专利数量及类型、商标、是否涉及IP纠纷
- **税务合规**：纳税信用等级（A/B/C/D）、欠税/骗税记录
- **严重违法记录**：区别于行政处罚，级别更高

---

### 维度六：财务健康信号

**上市公司**：
- 近3年营收及增长趋势
- 净利润及利润率
- **收入结构拆分**（⭐ 必须覆盖）：
  - 按业务线：各业务板块收入贡献及毛利率（如住宿预订/交通票务/度假旅游/商旅管理/广告及其他）
  - 按地域：国内 vs 海外收入占比及趋势
  - 各业务线增速对比（哪些在驱动增长）
- 资产负债率（>85%高风险）
- 经营活动现金流
- 审计意见（是否非标）
- 应收账款/商誉等关键科目是否有异常

**非上市公司（信号性判断）**：
- 融资轮次、金额、距今时间（>2年无融资需关注）
- 投资机构质量
- 债券违约 / 票据拒付记录
- 薪资拖欠 / 供应商欠款舆情
- 招聘规模变化趋势

---

### 维度七：管理层与核心人员画像

> ⭐ 求职场景最重要维度之一，也是投资场景判断"团队靠不靠谱"的核心。**必须逐人深挖，不能只罗列名字和职位。**

#### 7A. 创始人 / CEO

- 姓名、年龄、教育背景（学校/专业/学位）
- 完整职业经历（不仅当前职务，要回溯整个职业生涯的关键节点）
- 地域背景（籍贯/成长地，分析地缘资源网络）
- 个人公开言论、媒体专访（判断价值观和管理风格）
- 个人司法风险（失信/被执行/刑事）
- 社交媒体活跃度和公众形象
- **家族与社会关系**（⭐ 最容易遗漏）：
  - 配偶姓名、职业背景（是否涉及关联交易/同业）
  - 子女及其他近亲是否在公司任职或关联公司持股
  - 是否有家族办公室/私人投资平台

#### 7B. 董事会完整画像

> ⭐ 必须区分执行董事、非执行董事、独立非执行董事，不能混为一谈。

**董事会结构总览**：
- 总人数，各类董事人数（执行/非执行/独立非执行）
- 各委员会组成（审计/薪酬/提名/战略）
- 独立董事是否真正独立？（与公司/创始人是否存在历史关联）

**每位董事的完整画像**（逐人覆盖，不得遗漏）：

| 必须覆盖的信息 | 为什么重要 |
|--------------|-----------|
| 董事类型（执行/非执行/独立非执行） | 判断权力和独立性 |
| 年龄、教育背景 | 代际、学派网络 |
| **完整职业履历** | 能力背书、行业资源 |
| **历史战绩**（操作过哪些公司/项目） | 判断商业嗅觉和执行力 |
| **当前在其他公司担任的职务** | 利益冲突、资源网络 |
| **所在机构/基金的投资组合** | 判断背后资本力量 |
| 个人持股及薪酬 | 利益绑定程度 |
| 加入董事会时间 | 新旧程度，是否最近有变动 |

**⭐ 重点挖掘（最容易出情报的方向）**：
- 某位董事背后是否代表某家投资机构/某股势力？
- 某位董事历史操作过的公司/项目有哪些？战绩如何？
- 独立董事是否曾在公司关联方任职？（伪独立）
- 近2年离任董事都有谁？为什么离开？

**示例——携程董事李基培（Gabriel Li）**：
```
类型：独立非执行董事
历史战绩：曾任兰馨亚洲投资集团（Orchid Asia）管理合伙人，主导投资携程、
  易趣（eBay收购）、汽车之家（NYSE上市）、智联招聘、深信服科技（SZ上市）等
当前：审计委员会成员
背后力量：兰馨亚洲在管的PE/VC基金
```

#### 7C. 高管团队（C-Suite / VP级）

- 核心高管名单及职责
- 各自背景（来自哪些公司，是否有大厂/名校背书）
- **地域来源分布**（闽南系/湖南系/浙商系等地缘文化分析）
- **近1-2年高管离职情况**（频繁离职为重大预警信号）
- 是否有高管公开负面评价或争议事件

#### 7D. 关键人社会网络

> ⭐ 这个维度是理解"公司为什么能成事"的关键。

- **资本网络**：高管/董事关联的投资机构、PE/VC、基金
- **校友网络**：核心人物的校友圈（如清华系、交大系、斯坦福系等）
- **政府网络**：是否有人大代表/政协委员身份、政府顾问职务
- **行业网络**：在行业协会/标准组织中的任职
- **交叉任职**：同一董事在多家关联公司任职形成的网络

**风险信号**：
- CEO/创始人频繁更换
- 多名C级高管短期内集中离职
- 高管背景与业务方向严重不匹配
- 多名董事来自同一机构/派系（独立性风险）
- 独立董事与创始人有长期私交（伪独立）

### 维度八：组织结构与人员规模

> 了解公司"长什么样"，判断规模真实性和组织健康度。

**规模判断**：
- 官方公布员工人数 vs 招聘平台实际规模估算
- 社保缴纳人数（最真实的规模指标）
- 办公室数量及地点（总部+分支）

**组织层级**：
- 是否有公开的组织架构图
- 大致层级深度（扁平化 vs 科层制）
- 主要职能部门划分（研发/产品/销售/市场/运营/职能）

**各业务线 / 部门估算人数**：
- 通过招聘平台在招岗位分布估算各部门占比
- 技术 vs 销售 vs 运营的比例（反映公司类型：技术驱动 vs 销售驱动）
- 总部 vs 各地分支的人员分布

**风险信号**：
- 宣称千人规模但招聘平台显示极少岗位
- 某核心部门人员极少（如技术公司几乎无研发岗）

---

### 维度九：战略情报

> 通过招聘行为和重大事件反推公司战略重心，**不仅要看公司说了什么，更要看公司做了什么。**

#### 9A. 招聘分析

**覆盖平台**：Boss直聘、智联招聘、前程无忧、猎聘、拉勾、LinkedIn、脉脉、猎头渠道公开信息

**分析维度**：

① **当前主力招聘方向**
- 哪些岗位在大量招聘？（数量多 = 战略重点）
- 哪些岗位薪资显著高于市场？（愿意溢价的方向 = 核心押注）
- 是否在招聘某类特定背景人才？（如大量招"有XX行业经验"）

② **新业务 / 新项目信号**
- 是否突然出现大量某类新岗位？（新业务启动信号）
- 是否在招聘此前从未有过的职能？（业务扩张方向）
- JD 中提到的项目名称、产品名称、技术栈

③ **业务收缩信号**
- 某类岗位近期大幅减少或消失
- 是否有大规模裁员公告或招聘冻结

④ **技术方向判断**
- 技术岗 JD 中的技术栈（Go/Rust/Python/Java 等）
- 是否在布局 AI / 大模型相关岗位
- 研发岗位占总招聘比例

⑤ **管理风格信号**
- JD 描述风格（官僚式 vs 创业式）
- 是否强调"狼性"、"高压"、"结果导向"（文化预警）
- 福利描述的真实性（与员工评价交叉验证）

**输出格式**：
```
当前招聘重心：[方向1] / [方向2] / [方向3]
疑似新项目/业务：[根据JD推断]
技术方向：[主要技术栈]
招聘健康度：扩张中 / 稳定 / 收缩中
```

#### 9B. 重大事件深度解读

> ⭐ 重大事件不能只罗列事实，必须回答"这意味着什么"。

- **近2年重大事件清单**（监管行动、重大诉讼、并购、高层变动、业务调整等）
- **每个事件必须回答**：
  1. 发生了什么？（事实）
  2. 为什么发生？（背后原因——监管风向？内部矛盾？行业趋势？）
  3. 这意味着什么？（战略影响——对业务/估值/竞争格局意味着什么）
  4. 最坏情境是什么？（极端风险分析）
  5. 公司的应对如何？（评估管理层的危机处理能力）

**格式示例**：
```
事件：2026年1月 SAMR 反垄断调查

事实：市场监管总局突击检查携程上海总部，次日宣布就"涉嫌滥用市场支配地位"立案

背后原因：
├── 监管层面：互联网平台反垄断常态化，OTA行业集中度高（携程>50%份额）
├── 行业层面：酒店/航司对OTA高佣金率长期不满
└── 政治层面：释放"促进消费需降低中间成本"信号

战略影响：
├── 短期：罚款（参考阿里182亿、美团34亿），不构成生存威胁
├── 中期：可能被要求降低佣金率、开放数据接口、调整排他协议
└── 长期：行业竞争格局可能重塑，但龙头地位不易撼动

最坏情境：被强制拆分业务/限制特定品类运营（概率极低）
应对评估：目前公开信息有限，待观察
```

### 维度十：对外投资、合作与政商关系

> 了解公司的外部资源网络，判断政商关系深度和生态影响力。

**对外投资（直接/间接持股）**：
- 参股/控股企业名单及所属行业（与 4B 向下穿透联动）
- 被投企业中是否含国企 / 上市公司
- 被投企业健康状况（是否有风险传导）
- 对外投资趋势（扩张 vs 收缩）
- 是否有LP身份参与外部基金

**战略合作与生态归属**：
- 官方公布的重要合作伙伴
- 是否深度绑定某大生态（阿里系/腾讯系/华为系/字节系）
- 是否参与政府项目/智慧城市/数字化专项
- **公司到底是谁的"朋友"？**（通过股东、董事、业务合作综合判断）

**政府背景深度判断**：
- 是否承接政府采购项目（政府采购网可查）
- 是否获得国家/省级资质（专精特新 / 高新技术企业 / 独角兽 / 链主企业）
- 是否有政府领导公开站台或考察记录
- 注册地是否在特定政策区（国家级开发区/自贸区/特区）
- 地方政府是否持股或提供土地/补贴支持
- 是否参与国家重大项目/军民融合

**国资参与综合评级**：
- 🔴 无国资关联：纯市场化，无政府背书
- 🟡 弱国资关联：获政府补贴/认定，无直接持股
- 🟢 强国资关联：国资直接持股或为重要股东，政策稳定性高

### 维度十一：企业文化、价值观与雇主品牌

> 求职场景的核心参考维度，了解"这家公司值不值得待"。

**官方价值观**：
- 官网/招聘页公布的使命、愿景、价值观原文
- 创始人公开演讲/文章中体现的核心理念
- 是否言行一致（与员工评价交叉验证）

**员工真实评价**（多平台交叉）：
- Boss直聘员工评价
- 脉脉匿名评价（最真实，关注高频词）
- Glassdoor（外资/出海公司）
- 看准网 / 职场黑皮书
- **高频负面词预警**：大小周、画饼、PUA、派系、背刺、扣绩效、期权缩水

**工作强度与文化**：
- 是否大小周 / 996 / 强制加班
- 内部晋升机制是否透明
- 是否有强烈派系/山头文化
- 向上管理文化程度

**福利真实性核查**：
- 官方宣传福利 vs 员工实际反馈对比
- 五险一金缴纳基数（是否足额）
- 期权/股权兑现历史记录

**雇主品牌**：
- 是否获得"最佳雇主"认证
- 员工平均在职时长
- 整体推荐度评分

**输出格式**：
```
官方价值观：[关键词]
员工口碑：正面关键词 / 负面关键词
工作强度：低 / 中 / 高 / 极高
员工推荐度：高 / 中 / 低
文化风险提示：[具体问题]
```

### 维度十二：市场竞争格局

> ⭐ 不能孤立地看一家公司，必须放在竞争环境中评估。

- **细分市场定位**：
  - 每个业务板块的市场规模（TAM）
  - 公司在该市场的份额及排名
  - 近3年份额变化趋势（在增长还是被侵蚀）
- **主要竞争对手画像**（每个业务板块列1-3家）：
  - 对手名称、规模（市值/营收/用户数）
  - 对手的核心优势 vs 目标公司的差异
  - 是否在烧钱抢份额？
- **行业壁垒**：新进入者威胁、替代品威胁
- **上下游议价权**：对供应商（如酒店/航司）和对用户的话语权

#### 场景化建议

**💼 求职场景**（四大核心指标：劳动纠纷数量、员工评价、高管稳定性、招聘健康度）
- 🟢 低风险：公司经营稳健、文化健康，可放心推进，重点关注岗位匹配度和薪资结构
- 🟡 中风险：入职前明确薪资发放方式、确认五险一金足额缴纳，签署规范劳动合同，关注试用期条款
- 🔴 高风险：存在薪资拖欠、财务风险或文化严重问题，建议谨慎或放弃，优先考虑备选机会

**🤝 商务合作场景**
- 🟢 低风险：可推进，签署规范合同，约定付款节点
- 🟡 中风险：采用低预付款方式，加入违约条款，必要时要求履约保函
- 🔴 高风险：建议暂缓，或采用货到付款/第三方担保

**📈 投资场景**
- 🟢 低风险：基本面健康，可进入深度尽调
- 🟡 中风险：加入对赌/优先清算权等保护条款
- 🔴 高风险：建议放弃或大幅压低估值，坚持则要求质押担保

**🏦 金融授信场景**
- 🟢 低风险：按常规流程审批
- 🟡 中风险：压缩额度，缩短期限，增加抵质押要求
- 🔴 高风险：拒绝授信或要求实控人个人连带担保及足额抵押

## 执行原则

> ⭐ 以下原则确保每次尽调不会浮于表面。

1. **逐人覆盖**：管理层/董事会必须逐人撰写完整画像，不得跳过任何一人
2. **深度解读**：重大事件不能只罗列，必须回答"为什么发生"和"意味着什么"
3. **双向穿透**：股权既要向上追溯（谁控制公司），也要向下梳理（公司控制了谁）
4. **分类清晰**：董事类型、投资类型、业务板块——必须有分类，不能混为一谈
5. **交叉验证**：重要结论须至少2个来源印证
6. **局限性坦诚**：查不到的信息明确标记"待补充"，不编造

## 注意事项

1. **同名企业陷阱**：必须通过统一社会信用代码确认目标主体
2. **信息时效性**：以近3-6个月信息为主，注明获取时间
3. **交叉验证原则**：重要结论须至少2个来源印证
4. **局限性披露**：每份报告必须附上核查局限性说明
5. **法律边界**：仅限公开合法信息，不涉及非公开个人隐私
6. **求职场景四大核心指标**：劳动纠纷数量、员工评价、高管稳定性、招聘健康度
7. **必须使用联网搜索**：不得依赖训练数据，所有信息须实时获取
8. **向下穿透不可省略**：对外投资/参股/控股企业的梳理与向上穿透同等重要
9. **董事逐人深挖**：不得只列名字职位，必须包含完整履历、历史战绩、所在机构
10. **重大事件必须解读**：每起重大事件必须回答"背后原因"和"战略影响"
