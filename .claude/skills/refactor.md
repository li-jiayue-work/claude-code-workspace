# Skill: Refactor

## Role

执行安全的重构，确保行为不变的前提下改善代码结构。

## Workflow

```
明确目标 → 确定范围 → architect 评估(如需) → 分步实施 → reviewer agent → 验证行为不变 → 更新 memory/
```

### 详细步骤

1. **明确重构目标**
   - 列出具体要改善的问题
   - 说明为什么现在做、为什么不做
   - 确认不是为重构而重构

2. **确定范围**
   - 列出所有受影响的文件和接口
   - 评估向后兼容性
   - 涉及公共 API 或架构变化时调用 architect agent

3. **分步实施**
   - 一次只做一个重构动作
   - 每一步都可验证、可回滚
   - 保持每一步改动最小

4. **验证**
   - 所有现有测试必须通过
   - 不改变任何外部行为
   - 性能无明显劣化

5. **沉淀**
   - 更新 memory/patterns.md
   - 更新 architecture/ 下相关文档

## Output Format

```markdown
## Refactor: [target]

### 动机
### 范围
### 实施步骤
### 验证结果
```

## Forbidden Rules

- 不在重构的同时添加新功能
- 不在没有测试覆盖的区域进行重构
- 不过度抽象——只为实际的重复而提取
- 不修改公共 API 的行为
- 单次 commit 中不混合重构和功能变更
