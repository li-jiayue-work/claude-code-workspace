# 质量检查清单

## P0 来源门

每则材料的出处必须可追溯：

- 微信公众号内容需排除验证页（"环境异常"、"完成验证后即可继续访问"）
- 旧文件需核对来源链接是否仍有效
- 所有数字、人物和判断都要"回到原材料"
- 不得为凑页数或视觉效果编造信息

## P0 笔记门

- 幻灯片须按材料推进顺序展开，每页带有来源锚点
- 标题风格应像笔记而非导语
- 禁止空泛总结句或"不读原文也能写出来的漂亮概括"
- 关键张力与反常识判断必须显式呈现
- 结尾应停在材料留下的问题或原话上
- **可见文案禁用引号和破折号**（中文/英文/短破折号均禁止）
- 长材料末尾需有核心总结页，每条总结都要有具体锚点和获得感

## P0 版式门

- 每页只突出一个主重点，观众视线路径清晰
- 数字、原话、图片等证据享有最高视觉权重
- 正文 ≥ 24px，无溢出、遮挡或难以阅读的长段落
- 禁止网页式卡片堆叠、大面积渐变、无意义图标、假数据及过度圆角
- 表格与矩阵使用统一视觉语法（data-table / table-wrap）
- 三列数据必须同维度可比
- 大号原话不得超过 36 个中文字符
- 内容区内无右对齐文字
- 脚注不超过 18 个字符，仅标注来源或极短语境

## P0 HTML 门

- 交付物为单文件 HTML
- 每页需含 `data-theme`、`data-screen-label` 和真实的 `data-source` 锚点
- 所有 section 数量与导航数量一致
- 刷新后应回到当前页（localStorage 进度持久化）
- 脚本语法正常，无任何占位符或 TODO

## P1：更好

- 轻页、信息页、原话页与结构页交替出现
- 色调匹配材料气质
- 对话页保留提问的张力但回答仍是主声音
- 观众读完后能复述材料如何一步步展开
- 核心总结页读起来像高质量笔记，不像目录、口号或读后感
