# 微信公众号内容提取规则

## 验证页检测

微信公众号链接可能在非微信环境打开时返回环境验证页，而非真正正文。

### 检测关键词

- "环境异常"
- "完成验证后即可继续访问"
- "去验证"
- "请在微信客户端打开链接"

如果 `prepare_source.py` 发出 "possible WeChat validation page" 警告，不得继续生成 slides。

## 处理方式

遇到验证页时：

1. **优先**：在微信客户端中打开原文，复制正文粘贴为 md/txt 文件
2. **备选**：使用微信公众号导出工具导出为 HTML
3. **备选**：截图后手动转录为文本

## HTML 提取

对于微信公众号 HTML：

- 正文通常在 `<div id="js_content">` 中
- 标题在 `<h1 class="rich_media_title">` 或 `og:title` meta 中
- 作者在 `var nickname = "..."` 或 `#js_name` 中
- 发布时间在 `var ct = "..."` 或 `publish_time` 中

## 注意事项

- 微信公众号图片链接通常有防盗链，slides 中不应直接引用
- 旧文件需核对本地缓存是否过期
- 同一篇文章的多次编辑版可能导致来源不一致
