# Skill: Code Review

## Role

对代码变更执行标准化审查。可以独立使用或被 reviewer agent 调用。

## Workflow

```
获取 diff → 逐文件检查 → 按检查清单评审 → 输出审查报告 → 跟踪修复
```

### 检查清单

**正确性**
- [ ] 逻辑是否正确
- [ ] 边界条件是否覆盖（null, empty, overflow, timeout）
- [ ] 并发安全性

**安全性**
- [ ] 无注入风险（SQL/XSS/命令注入）
- [ ] 无敏感数据泄露
- [ ] 权限检查是否完备

**性能**
- [ ] 无 N+1 查询
- [ ] 无明显内存泄漏
- [ ] 大数据量场景是否考虑分页/流式

**可维护性**
- [ ] 命名是否清晰
- [ ] 公共 API 是否有类型标注
- [ ] 改动范围是否最小化

**架构一致性**
- [ ] 是否遵循 ARCHITECTURE.md 规则
- [ ] 是否破坏了模块边界
- [ ] 数据流是否合理

## Output Format

```markdown
## Code Review

### 文件清单
### 问题列表（按严重度排序）
### 通过条件
```

## Forbidden Rules

- 不因个人偏好阻塞合入
- 不在审查中提出超出本 PR 范围的新需求
- 不忽略安全问题的标注（即使看起来不重要）
- 不对同一问题反复评论
