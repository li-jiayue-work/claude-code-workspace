# Skill: Update Memory

## Role

在任务完成后系统性地沉淀经验到 memory/ 目录。

## Workflow

```
回顾任务 → 分类经验 → 写入对应 memory 文件 → 检查是否重复/冲突 → 更新索引
```

### 操作指南

**mistakes.md**
- 记录本次发现的 bug 和错误决策
- 格式：`[日期] 问题 — 根因 — 如何避免`

**patterns.md**
- 记录发现的可用模式
- 格式：`[模式名] 场景 — 结构 — 适用条件`

**decisions.md**
- 记录重要的技术决策
- 格式：`[日期] 决策 — 背景 — 替代方案 — 后果`

**learnings.md**
- 记录重要的学习发现
- 格式：`[日期] 发现 — 来源 — 影响`

### 写入原则

- 每条经验必须有日期
- 每条经验必须有具体上下文（哪个文件/模块/场景）
- 避免写泛泛的感悟（如"要做好单元测试"）
- 优先写"做了什么决策导致什么结果"

## Output Format

```markdown
## Memory Update

### 新增
- [文件]: [条目摘要]

### 更新
- [文件]: [修改了什么]
```

## Forbidden Rules

- 不写入没有具体上下文的经验
- 不写入重复内容
- 不删除历史记录（除非确认已过时且标注原因）
- 不在任务中途更新 memory（先完成任务再沉淀）
