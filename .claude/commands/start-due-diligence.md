# 启动企业深度尽职调查

## 触发方式
当用户说以下任何一种，立即执行本流程：
- "帮我尽调 / 背调 XX 公司"
- "查一下这家公司"
- "这家公司靠谱吗 / 有没有风险"
- "做个 DD / 尽职调查 / 深度分析"
- "我想入职 XX 公司，帮我了解一下"
- "我想了解 XX 公司的战略 / 管理层 / 文化"

---

## 执行流程

### 第一步：确认信息
若用户未提供以下信息，先询问：
- 目标企业全称（必须）
- 调查目的/场景：求职 / 商务合作 / 投资 / 金融授信（必须）
- 统一社会信用代码（可选，有则更准确）
- 是否有特别关注的维度（可选）

### 第二步：展开调查
1. 加载 `.claude/skills/due-diligence/SKILL.md`
2. 全程使用联网搜索，覆盖十二大维度
3. **每条关键数据必须记录来源**：
   - 来源平台/网站名称
   - 原始链接 URL
   - 获取时间（精确到日期）
   - 关键原文摘录（不超过50字）

### 第三步：输出报告
- 输出完整结构化深度情报报告（格式见 SKILL.md）
- 报告开头附"一句话结论"
- 报告末尾附"核查局限性说明"

### 第四步：自动保存（每次调查结束后必须执行）

**4.1 确认保存目录存在，不存在则创建：**
```
docs/due-diligence/
```

**4.2 保存完整报告：**
文件名格式：`{公司简称}_{YYYYMMDD}.md`
保存路径：`docs/due-diligence/{公司简称}_{YYYYMMDD}.md`
内容：完整尽调报告全文

**4.3 保存数据来源存档：**
文件名格式：`{公司简称}_{YYYYMMDD}_sources.md`
保存路径：`docs/due-diligence/{公司简称}_{YYYYMMDD}_sources.md`

来源存档格式如下：
```markdown
# 数据来源存档 — {公司全称}
调查日期：{日期}

## 维度一：主体基础信息
- 来源：企查查
  链接：https://...
  获取时间：2025-05-10
  摘录：注册资本1000万元，实缴比例100%

## 维度二：工商合规风险
- 来源：国家企业信用信息公示系统
  链接：https://...
  获取时间：2025-05-10
  摘录：近3年无行政处罚记录

（以下各维度同格式）
```

**4.4 更新索引文件：**
在 `docs/due-diligence/index.md` 中追加一行记录：
```markdown
| {日期} | {公司全称} | {调查场景} | {综合风险评级} | {一句话结论} | [{报告}](./{文件名}.md) |
```
若 index.md 不存在，则新建并加上表头：
```markdown
# 企业尽调档案索引

| 日期 | 公司名称 | 调查场景 | 综合评级 | 一句话结论 | 报告链接 |
|------|---------|---------|---------|-----------|---------|
```

**4.5 更新经验记录：**
在 `memory/decisions.md` 中追加本次调查的关键风险规律，格式：
```markdown
## {日期} — {公司简称}尽调经验
- 行业：{所属行业}
- 综合评级：{评级}
- 关键风险点：{1-3条最重要的发现}
- 可复用规律：{对同类公司调查有参考价值的规律}
```

### 第五步：保存完成后告知用户
输出以下提示：
```
✅ 报告已保存至：docs/due-diligence/{文件名}.md
✅ 来源存档已保存至：docs/due-diligence/{文件名}_sources.md
✅ 索引已更新：docs/due-diligence/index.md
✅ 经验已沉淀至：memory/decisions.md
```

## 求职场景四大核心指标（优先调查）
1. 劳动纠纷数量与趋势
2. 多平台员工真实评价
3. 近1-2年高管稳定性
4. 招聘规模健康度

---

## 注意事项
- 必须使用联网搜索，不得依赖训练数据
- 同名企业须通过信用代码确认目标主体
- 重要结论须至少2个来源交叉印证
- 数据来源必须在调查过程中实时记录，不得事后补填
- 若某维度因信息不可获取而无法完成，须在报告中明确注明"数据不可获取"及原因
