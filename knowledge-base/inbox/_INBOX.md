# Inbox — 快速捕获

## 使用方法

1. 每次 AI 对话结束后，如果学到了有意思的东西，在本目录创建一个文件：
   `YYYY-MM-DD-简短主题.md`

2. 粘贴有趣的对话片段。**不要格式化，不要分析。**

3. 在文件第一行写：`保存原因：[一句话]`

4. 完成。整个过程不超过 60 秒。

## 处理规则

每周 review inbox 中的文件：
- 提取值得保留的片段 → 创建 Layer 1 Raw Note（见 `../templates/template-1-raw-note.md`）
- 处理完成后，在 inbox 文件第一行添加 `[已处理 YYYY-MM-DD]`
- **不要删除 inbox 文件**——它们是原始来源日志

## 示例

文件 `2026-05-10-中国财政政策.md`：

```
保存原因：第一次听到"准宪法性"这个分析视角

AI 提到中国财政体制中，1994 年分税制改革在事实上形成了
中央与地方的财政契约，虽然法律上可以随时修改，但实践中
已经形成了稳定的预期和博弈规则，这种"准宪法性"约束力
在很多后发国家的财政体系中都有体现。
```
