# Knowledge Base — 个人知识库

## 这是什么

一个**按认知深度而非按话题**组织的个人知识库。所有知识来源于与 AI 的对话，涵盖政治体制、国家发展、文化差异、商业观察等领域。

## 核心理念

不按"中国政治"、"美国经济"这样的话题分类，而是按**你是如何思考的**来分类。

知识沿六层阶梯逐级蒸馏：

```
Raw Notes（原始笔记）→ Observations（观察）→ Patterns（模式）
→ Principles（原则）→ Frameworks（框架）→ Viewpoints（观点）
```

## 快速开始

### 第一次使用

1. 阅读 [WORKFLOW.md](./WORKFLOW.md) 了解完整流程
2. 浏览 [templates/](./templates/) 熟悉各层模板
3. 下次 AI 对话结束后，在 [inbox/](./inbox/) 做第一次捕获

### 日常使用

- **每次对话后** → inbox 捕获（60 秒）
- **每周** → 提取到 Raw Notes（15 分钟）
- **每月** → 蒸馏为 Observations 和 Patterns（30 分钟）
- **每季度** → 概括为 Principles 和 Frameworks（1 小时）
- **每半年** → 综合为 Viewpoints（2 小时）

## 洞察类型

每条经过加工的条目都标记一个"认知动作"类型（而非主题标签）：

- `causal-mechanism` — 因果机制
- `structural-comparison` — 结构性比较
- `counterintuitive` — 反直觉发现
- `historical-trajectory` — 历史演变轨迹
- `leverage-point` — 杠杆点
- `constraint-identification` — 约束识别
- `value-tradeoff` — 价值权衡
- `pattern-recognition` — 模式识别
