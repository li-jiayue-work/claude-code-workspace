# ai-workflow-notes

记录和沉淀 AI 辅助开发的协作方法论，把每次成功的实践固化为可复用的标准。

## 包含内容

```
architecture/    ← 架构设计文档
docs/            ← 参考文档与工具说明
knowledge-base/  ← 知识库与经验积累
workflows/       ← 标准任务流程定义
CLAUDE.md        ← AI 行为规范与编写准则
```

## 核心方法论

- 如何写让 AI 可执行的指令——上下文质量决定输出质量
- 如何在 AI 辅助下保持项目控制力——最小修改原则
- 如何把工作流标准化——从靠运气变成靠流程
