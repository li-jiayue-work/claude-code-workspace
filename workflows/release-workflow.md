# Workflow: Release

## 阶段

```
准备 → 冻结 → 验证 → 发布 → 监控 → 复盘
```

## 步骤

### 1. 准备 (T-3d)

- 确认 ROADMAP.md 中计划内容完成
- 审查所有待合入 PR
- 确认 PROJECT.md 中已知问题状态
- 检查外部依赖是否就绪

### 2. 冻结 (T-2d)

- 代码冻结：只合入 P0 bug fix
- 完整回归测试
- 安全扫描

### 3. 验证 (T-1d)

- 预发布环境部署
- 冒烟测试
- 性能压测（如有）
- 回滚方案确认

### 4. 发布 (T-day)

- 按发布步骤执行
- 监控关键指标
- 团队可联系

### 5. 监控 (T+3d)

- 错误率
- 用户反馈
- 性能指标
- 如有问题触发 emergency-debug

### 6. 复盘 (T+5d)

- 总结发布过程的问题
- 更新 memory/learnings.md
- 更新 ROADMAP.md
- 评估流程改进

## Rollback 条件

- P0 问题：立即回滚
- P1 问题 > 3 个：评估回滚
- 数据一致性问题：立即回滚

## 禁止事项

- 不在冻结后合入非 P0 变更
- 不跳过预发布验证
- 不忽略监控期
- 不跳过复盘
